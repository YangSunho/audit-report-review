# ARI — Audit Review Intelligence

DART 감사보고서(`.dsd`) **원본을 그대로** 넣으면 되는 도구입니다. 변환도, 내보내기도 필요 없습니다.

**👉 [바로 사용하기](https://yangsunho.github.io/audit-report-review/)**

도구는 둘이고, 한 화면에서 고릅니다.

| | 넣는 것 | 하는 일 |
|:--|:--|:--|
| **검토** | `.dsd` 1개 (여러 개도 가능) | 합계·주석·연계성·기간 연속성·표기까지 62종을 전수 대사합니다 |
| **비교** | `.dsd` 2개 | 두 판(版)을 계정명·주석 제목으로 짝지어 봅니다. 한 줄이 삽입돼도 뒤가 통째로 「변경」으로 밀리지 않습니다 |

> 예전에는 검토(`/`)와 비교(`/compare/`)가 따로 있었습니다. 지금은 **한 파일**에 합쳐졌고,
> 예전 `/compare/` 주소는 통합본의 비교 화면으로 넘어갑니다.

## 무엇을 하는가

| | 내용 |
|---|---|
| **기계 검증** | 세로합계·가로합계·증감정합(Roll-forward)·주석 참조를 전수 대조 |
| **재무제표 연계성** | 자본변동표를 축으로 재무상태표·손익계산서·현금흐름표를 서로 대사 — 이익잉여금 증감이 당기순이익·배당으로 설명되는지, 기타자본 변동이 기타포괄손익과 맞는지 |
| **정합성** | 대차평균, 기말현금 대사(CF↔BS), 표지 요약수치 대조 |
| **증감분석** | 당기·전기 유의적 변동 계정 추출 |
| **심리 예상 질의** | 유의적 변동과 재무제표 간 관계를 근거로 심리 단계에서 나올 질문 도출 |
| **보고기간후사건** | K-IFRS 1010 관점 점검 항목 + DART·뉴스 검색 보조 |
| **산출물** | 검토 결과(HTML) · 엑셀 워크북 · 워드 리포트 |

## 설계 원칙

- **결정론 우선** — 모든 계산·대사는 코드가 수행합니다. 수치를 지어내지 않습니다.
- **오류를 단정하지 않음** — 기계가 확정할 수 있는 것만 "불일치"로 표시하고, 나머지는 근거와 함께 "확인이 필요한 항목"으로 제시합니다.
- **원본 불변** — `.dsd` 원본은 읽기만 하며 변경하지 않습니다. 파일 해시를 결과에 기록합니다.
- **로컬 처리** — DSD 파싱·검증·보고서 생성이 전부 접속자 브라우저 안에서 일어납니다. 외부로 나가는 통신이 없습니다.
- **인식 진단** — 보고서를 충분히 읽지 못했으면 결과보다 먼저 그 사실을 표시합니다. 조용한 빈 결과로 잘못된 안심을 주지 않기 위해서입니다.

## 오프라인·폐쇄망 사용

배포된 사이트에서 [`감사보고서_도구.html`](https://yangsunho.github.io/audit-report-review/감사보고서_도구.html)
파일 하나를 내려받으면, 인터넷 없이 더블클릭만으로 똑같이 동작합니다.
검토와 비교가 그 한 파일 안에 다 들어 있습니다.

## 이 저장소에 있는 것

**완성된 앱 한 파일**입니다. 소스 코드는 두지 않습니다.

| 파일 | 내용 |
|:--|:--|
| `앱/감사보고서_도구.html` | 실제로 돌아가는 앱 전부. 배포되는 것이 이 파일입니다 |
| `앱/compare-redirect.html` | 예전 `/compare/` 주소로 들어온 사람을 비교 화면으로 보냅니다 |

소스를 두지 않는 이유는 둘입니다. 첫째, 엔진을 고쳐도 저장소 사본은 옛것으로 남아
**공개된 코드와 실제로 돌아가는 앱이 어긋났습니다.** 둘째, 코드 주석에는 개발에 쓴
감사 대상 회사 이름이 남기 쉽습니다. 완성된 앱에는 주석이 들어가지 않습니다.

### 올라간 것이 확인한 것과 같은지 보는 방법

앱 화면 맨 아래에 **엔진 지문**(12자리)이 적혀 있습니다. 같은 소스에서 만들면 언제
만들어도 같은 값이 나오므로, 화면의 값과 배포자가 밝힌 값을 견주면 됩니다.

## 한계와 책임

이 도구는 감사인의 검토를 보조합니다. 감사 판단과 조서 작성의 책임은 사용자에게 있습니다.
표시 형식이 예상과 다른 보고서는 일부만 인식될 수 있으며, 그 경우 앱이 인식 범위를 먼저 알립니다.
